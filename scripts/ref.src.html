Design system reference

Seeghra

IBM Carbon v11, taken verbatim, set in Geist Sans and Geist Mono. Corners are square everywhere and everything aligns to the left edge.

Every colour, size and space on this page reads from tokens.css. Use the theme control at the top to check all four Carbon themes. Auto follows your system setting: White in light mode, g100 in dark mode.

Geist adjustments

Geist was measured against IBM Plex with fontTools and rendered in Chromium at every Carbon size. Its line box is the same height as Plex (1.300 em), so no line height moves. Mixed text runs about 2 percent wider, which does not change line counts in any fixed-height component. Only the items below change.

Spacing

Carbon's 13 step spacing scale, built on a 2 px mini unit and 8 px rhythm.

Layout sizes

Component heights. Buttons, inputs, dropdowns, toolbars and table rows all snap to these six sizes.

Grid

Carbon's 2x grid: 4 columns on small, 8 on medium, 16 from large up, with a 32 px gutter. Carbon centres the grid container at its maximum width; Seeghra pins it to the left edge.

Motion

Six durations and two easing styles. Productive motion is for small, frequent UI changes; expressive motion is for larger moments such as opening a modal.

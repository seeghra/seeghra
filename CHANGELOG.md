# Changelog

## 1.0.0

First public release.

- Every IBM Carbon v11 token, prefixed `--sg-`, in CSS and JSON.
- White, g10, g90 and g100 themes, with automatic dark mode.
- Geist Sans and Geist Mono in place of IBM Plex. Carbon sizes, weights, line heights and letter spacing unchanged.
- Geist Pixel as five opt-in font tokens.
- Zero radius and start alignment throughout.
- Reference page with foundations and ten components in every state.
- Claude skill for building Seeghra pages, PDFs and slides.

Built from @carbon/themes 11.83.0, @carbon/styles 1.117.0, @carbon/type 11.69.0, @carbon/layout 11.61.0, @carbon/motion 11.54.0, @carbon/colors 11.60.0, @carbon/icons 11.90.0 and geist 1.8.1.
